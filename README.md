# 音の棚 — Otonotana

iPhone向けのローカル音楽プレイヤー。PCで歌詞の開始時刻を設定し、iPhoneで歌詞をタップしてその部分から再生できます。SwiftUI / AVAudioPlayer、iOS 17以降。ストア配信や音楽のオンライン取得は行いません。

## 0.3版

0.3.4では、USB共有ファイルのパスを文字数で切り取っていた不具合を修正しました。同じ保存先でも `/var/...` と `/private/var/...` の表記差があると、誤った `cuments/曲名.m4a` を組み立てて読み込めなくなっていました。両方のURLをシンボリックリンク解決・正規化してからフォルダー単位で位置を求め、通常のファイル選択にも同じ方法を使います。保存場所の別名による再現テスト、元ファイルの読み取り、保存先外へのリンクの拒否を確認します。再スキャン時には古い失敗結果も整理します。

0.3.3では、外観の連動設定を「システム設定に従う」に変更しました。曲情報の編集欄には項目名を常時表示し、ディスク番号・ジャンル・発売年・作曲者・メモを追加しました。ジャンル・発売年・作曲者はm4aの情報も参照します。ファイル名・ファイル形式・サイズは確認専用です。

USB共有の音楽を開けない場合は、追加コピーを作らず少し待って最大3回読み取ります。失敗したファイル名・サイズ・処理・エラー内容を「設定 → 読み込み結果」に残します。転送途中・形式・アクセス・一覧保存などの問題を、原因不明のまま転送未完了と決めつけない表示にしました。AAC／ALACのm4aを日本語・空白・括弧を含む共有フォルダーへ直接配置するテストと、開けないファイルのエラー表示を追加しています。個別の実機で起きた読み込み失敗の原因は、詳細結果を確認する必要があります。

0.3.2では、曲／アルバム／アーティストの切り替えを文字の外側の余白でも押せるようにしました。シークバーはつまみのドラッグに加えて途中のタップにも対応し、再生中／一時停止の状態を保って移動します。設定の「アプリの外観」でライト／ダーク／本体設定に合わせるを選べます。再生画面のジャケット・ミッドナイト・ペーパーのテーマは独立して選べます。

0.3.1では、アルバムのジャケットを上端で揃え、曲名欄を2行分・アーティスト欄を1行分確保して文字数による上下のずれを修正しました。また、再生時間の更新を独立した時計に分離し、時間表示と歌詞だけが定期更新を受け取るようにしました。メニューと再生画面全体の再描画・位置計算を毎回やり直すのを防ぎます。長短のアルバム名での位置比較と、再生中のメニューの表示・編集操作をUIテストで確認します。

- ライブラリを曲／アルバム／アーティストで切り替え。切り替え時は横に短くスライドし、実際のスワイプ操作は不要です。「視差効果を減らす」設定では移動を抑えます。
- 曲一覧はジャケットを省き、曲名・アーティスト・アルバムを表示。検索はこの3種類の情報に対応します。
- アルバムは2列のジャケット一覧、収録曲画面、アルバム内での再生／シャッフルに対応。
- m4aなどの曲名・アーティスト・アルバム・アルバムアーティスト・ディスク番号・収録順・ジャケットを参照。情報がない曲は手動で編集できます。
- 「＋」から手動のアルバムを作成し、曲をまとめ、収録順を並べ替え、共通ジャケットを設定できます。編集内容は音楽ファイルを書き換えずアプリ内に保存します。
- 下部は等間隔のライブラリ／プレイリスト／設定タブと、タブを切り替えても使えるミニプレイヤー。
- プレイリスト作成・編集・並べ替え・削除、お気に入り、最近追加した曲。プレイリストは曲IDを保存し、音楽を複製しません。
- 再生画面はジャケットの代表色を強めに反映。ミッドナイト／ペーパーも設定タブから選べます。
- 左下の吹き出しで歌詞画面へ。ジャケット画面では前・現在・次の歌詞を表示し、歌詞の開始時刻になった時だけ短く移動します。
- 歌詞画面はコンパクトな曲情報、文字サイズの小／標準／大、自動スクロールON／OFF、上下端のフェード。OFFでは強調だけ更新し、閲覧位置を動かしません。歌詞タップはどちらの設定でも使えます。
- 歌詞の秒数表示ON／OFFと歌詞プレビューON／OFFは設定タブ。
- シャッフル、リピートOFF／全曲／1曲。曲一覧・検索結果・アルバム・プレイリストなど、再生を開始した一覧を再生対象にします。シャッフルの「前」は実際に再生した履歴へ戻ります。
- バックグラウンド再生、ロック画面操作、AirPlay、割り込み・イヤホン切断時の停止。

## PCからUSBで直接追加

1. iPhoneをWindows PCへ接続し、必要に応じてiPhoneでPCを信頼する。
2. iTunesの「ファイル共有」、またはAppleデバイスのファイル画面で **Otonotana** を選ぶ。
3. m4aなどの音楽と、同じ名前のUTF-8 LRCを追加する。例：`曲名.m4a` と `曲名.lrc`。
4. ジャケットは `曲名.jpg`／`曲名.png`、または同じフォルダーの `cover.jpg`／`cover.png` を使用できる。音楽に埋め込まれたジャケットも読み込む。
5. 転送完了後にiPhoneで音の棚を開く。新しい曲・歌詞・画像が自動登録される。反映されない場合は「設定 → 共有ファイルを再読み込み」。

受け取った音楽はアプリのDocuments内に1つだけ保存し、その場所から直接再生します。登録のための追加コピーや音楽の再圧縮は行いません。確認は起動・前景復帰・手動更新時に行い、再生ごとに全ファイルを読み直しません。変更のないファイルは再解析せず、ファイルサイズ・更新時刻を確認します。

0.2以前の曲は初回起動時にDocuments内のMusicフォルダーへ**移動**し、曲ID・歌詞・お気に入り・ジャケットを引き継ぎます。追加の音楽コピーは作りません。移動と一覧保存の途中で終了しても、次回起動で復旧できるよう元の保存場所と移動先を確認します。

「＋ → 音楽ファイルを追加」で外部の「ファイル」から選ぶ方法も残しています。この方法はオフラインで使うためアプリのDocumentsへ1回コピーするので、外部の元ファイルも残ります。容量の二重使用を避けたい場合はUSBファイル共有、または「このiPhone内 → Otonotana」への移動を使ってください。他のアプリの元ファイルを勝手に削除しません。同じ音楽を別の名前・場所で追加すると別の曲として登録されます。

## PCで歌詞の開始時刻を設定

1. `PCEditor/index.html` をEdgeやChromeで開く。PCEditor内のファイルは同じ場所に置く。
2. 音楽を選択し、歌詞を1行ずつ貼り付ける。
3. 再生しながら歌い始めに「選択行に今の時刻 → 次の行」を押す。Ctrl＋Enterにも対応。
4. 秒数を手入力、または±0.1秒で調整。「ここから再生」で確認する。
5. 「LRCを保存」で書き出し、iPhoneには同じ音楽と一緒に転送する。

下書きはJSONとして保存・再読込できます。音楽・歌詞を外部へ送信しません。ALACのm4aをブラウザで再生できない場合は秒数の手入力も使えます。PCとiPhoneで別バージョンの音楽を使うと歌詞の位置がずれるため、同じファイルを使ってください。

## 更新版のインストール

WindowsのAltServerで以前と同じAppleアカウントを使い、IPAを上書きインストールします。**既存アプリは削除しないでください。** アプリ削除は保存した音楽・歌詞・プレイリストも削除します。無料署名の更新は通常7日ごとに必要です。

公開リポジトリの標準macOSランナーを使い、GitHub ActionsでIPAをビルドします。課金を伴う実行を避けるため、リポジトリが非公開のときはビルドをスキップします。IPAは未署名なのでAltServerなどで署名してから導入します。

- 最新のビルド: https://github.com/tokage0523/otonotana/actions
- AltStore Classic Windows手順: https://faq.altstore.io/altstore-classic/how-to-install-altstore-windows

## 検証

PCの歌詞形式テスト：`node PCEditor/lyrics-core.test.cjs`。
GitHubのmacOSでSwiftのLRC解析、旧Trackの互換性、アルバム分類・収録順、プレイリストの保存、再生順・シャッフル履歴・リピート、共有ファイルのパスを確認します。
XcodeのUIテストで歌詞タップ、自動スクロール設定の保持、文字サイズ、等間隔の配置、アルバム表示、プレイリストの再起動後の保持、共有音楽と同名LRCの登録を確認し、画面画像を出力します。テスト用の音楽・歌詞・ジャケットは架空のもので、Release版には生成処理を含めません。

AAC／ALACの実際の音楽、USB転送、実機のバックグラウンド・ロック画面操作はiPhoneでの確認も必要です。0.3の実機確認はユーザーの端末で行います。
