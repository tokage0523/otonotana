# Windows歌詞エディター

Windows 10 / 11 x64向けのインストール不要のデスクトップアプリです。ブラウザー版と同じPCEditorを内蔵し、Windowsのメニュー、ショートカット、保存ダイアログを提供します。音楽はファイル選択で直接参照し、追加コピーしません。

公開用ファイルは `publish/OtonotanaEditor.exe`、`使い方.txt`、`Licenses/`。ZIPを展開してexeを起動します。WebView2 Runtimeが必要です。.NET Runtimeはexeに同梱するため、別途インストール不要です。

## 開発とビルド

Windowsと.NET SDK 8以降を使用します。

```powershell
./build.ps1
./verify.ps1
# 実際のAAC M4Aも確認する場合（新しいテスト専用フォルダーを使用）
./verify.ps1 -M4AFixture 'C:/path/to/test.m4a'
```

検証では非表示の実際のWindowsアプリを専用プロファイルで2回起動し、ネイティブ保存の結果、保存キャンセル、不正な拡張子の拒否、ブラウザー版JSONの統合、音声のデコードと再生・打刻、終了後の下書きの復元を確認します。保存先の選択だけはテスト用フォルダーへ差し替えます。ユーザーの下書きを参照・変更しません。

## 保存と移行

自動保存は `%LOCALAPPDATA%/Otonotana/LyricsEditor/Profile`。画面の仮想ホストと保存先を固定し、exeの移動・更新後も引き継ぎます。音楽本体は下書きに含みません。

ブラウザー版の自動保存は別の保存領域です。ブラウザー版で「全下書きを保存」したJSONを、アプリの「保存済みの歌詞を開く」から読み込んで移行します。旧1曲分JSONとLRCも読み込めます。

UIはアプリ内に埋め込み、外部ページへの移動・外部リソース読み込み・不要な権限要求を止めています。保存ブリッジは歌詞本文と保存名だけを受け取り、ユーザーがWindowsのダイアログで選んだ場所へUTF-8で保存します。選択前に書き込みません。
